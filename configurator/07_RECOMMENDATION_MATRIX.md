# Recommendation Matrix

## Goal tiers

### Gaming

| User goal | Suggested GPU tier | RAM | Storage | Monitor target |
|---|---|---:|---:|---|
| Smooth everyday gaming | value | 16GB | 1TB | 1080p / 144Hz-class |
| High FPS competitive | balanced | 16GB | 1TB | 1080p high-refresh / 1440p |
| High-quality 1440p/4K | performance | 32GB | 2TB | 1440p high-refresh / 4K |

### Workstation

| User goal | Suggested emphasis | RAM | Storage |
|---|---|---:|---:|
| Video/photo work | strong GPU + fast CPU | 32GB | 1TB+ |
| 3D/CAD/rendering | GPU + CPU balance | 32GB | 1TB+ |
| Coding/AI/heavy multitasking | CPU + RAM + GPU headroom | 32-64GB | 1TB+ |

These are recommendation defaults, not hard product requirements.

## Priority mapping

### Best Value
- choose lower-cost part from the valid tier;
- prefer 16GB over 8GB for modern gaming/workstation entry builds where budget allows;
- 1TB storage as default when catalog economics permit;
- air cooling unless thermal requirements make it unsuitable.

### Balanced - Recommended
- choose the mid-tier compatible component;
- keep CPU/GPU balanced;
- 16GB or 32GB depending on workload;
- 1TB NVMe default;
- stronger PSU headroom;
- better case airflow.

### Maximum Performance
- choose top valid component for the selected workload;
- 32GB/64GB where justified;
- 2TB+ storage where justified;
- higher PSU tier;
- stronger cooling;
- high-refresh/high-resolution monitor for complete setups.

## Customer-facing labels

Do not show raw tier words alone. Use:
- Best value
- Recommended
- More performance

Avoid:
- Entry-level
- SKU tier
- TDP class
- PCIe lane count
- chipset jargon
