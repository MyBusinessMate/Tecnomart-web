## 3. SEO Architecture

TecnoMart utilizes a **dual-layer SEO architecture** designed to solve SPA crawlability:

```
[ HTTP Request from Bot / Crawler / User ]
                    │
                    ▼
          Vercel Static Edge
                    │
   ┌────────────────┴────────────────┐
   ▼                                 ▼
Bot / Crawler Request         Client Browser Navigation
(GET /laptops, /mobiles/...)   (React Router CSR Navigation)
   │                                 │
   ▼                                 ▼
Pre-rendered Static Snapshot   `src/components/SEO.jsx`
Generated by:                  Dynamic useEffect Hook
`scripts/prerender-seo.js`     Mutates:
- Static <title>               - document.title
- Static <meta name="description"> - <meta name="description">
- Static <link rel="canonical"> - <link rel="canonical">
- Static Open Graph / Twitter  - Open Graph / Twitter Tags
- Static JSON-LD Schema Script - Dynamic JSON-LD Script tag
- Static Prerendered HTML      - Geo-targeting Meta Tags
```

### Build-Time Pipeline (`package.json:10`)

```bash
npm run build
  ├── 1. node scripts/generate-sitemap.js  -> Generates public/sitemap.xml (103 URLs with Google Image XML tags)
  ├── 2. vite build                       -> Bundles client assets to dist/
  └── 3. node scripts/prerender-seo.js    -> Injects route-specific SEO snapshots into dist/ for all 103 routes + 404.html
```

## 33. Potential Issues & Observations

During the forensic inspection, the following potential issues and inconsistencies were identified:

1. **Twitter Handle Inconsistency:**
   * In `index.html:43` & `src/components/SEO.jsx:450`: Twitter handle is `@tecnomart_hyd`.
   * In `public/llms-full.txt:25`: Twitter URL is listed as `https://twitter.com/tecnomart_in` (`_in` vs `_hyd`).
2. **Title / Description Variations between Static Snapshot and React CSR:**
   * On `/mobiles`: `scripts/prerender-seo.js` renders `Best Mobile Shop in Hyderabad | Buy iPhones, Samsung Galaxy & Flagships | TecnoMart`, while `src/app/mobiles/page.jsx` sets `Best Mobile Shop in Hyderabad | Buy iPhones, Samsung Galaxy & Flagship Phones` (which CSR appends ` | TecnoMart Hyderabad`).
   * *Impact:* Search bots inspecting the static pre-render see one title, while users after client-side hydration see a slight variation.
3. **Unused Legacy Next.js Artifact:**
   * `src/app/layout.jsx` contains Next.js exports (`export const metadata`, `export const viewport`, `Plus_Jakarta_Sans`). Because the project is powered by Vite (`index.html` → `src/main.tsx` → `src/App.tsx`), `src/app/layout.jsx` is entirely dead code and not used by the build or browser.
4. **Lighthouse / Headless Bot Suppression in Hero:**
   * In `src/components/redesign/HeroSection.jsx:87-91`, a `navigator.userAgent` check suppresses loading the 3D canvas model when Lighthouse or headless Chrome is detected. While this optimizes Lighthouse performance metrics, caution is advised to ensure search engine crawlers do not perceive differences in layout stability.
5. **Commented-Out Store Authority Sections:**
   * In `index.html:199-244`, a comprehensive "STORE AUTHORITY & SPECIFICATIONS TABLE" with articles for Mobiles, Laptops, Repairs, PC Builds and store details is currently wrapped in HTML comments.
   * In `src/app/page.jsx:123-128`, `<StoreAuthorityOverview />` is commented out.

```
  Run: npm run build
  (Executes generate-sitemap.js -> vite build -> prerender-seo.js)
                         │
                         ▼
[ Step 5: Verify Changes in dist/ Output ]
  Check that dist/<route>/index.html contains updated meta & schema
```

### Specific Update Scenarios

#### Changing the Storefront Domain
If the primary domain changes:
1. Update `STORE_DOMAIN` in `src/lib/domain.ts`
2. Update `DOMAIN` in `scripts/generate-sitemap.js` and `scripts/prerender-seo.js`
3. Update `BASE_URL` in `src/components/SEO.jsx`
4. Update `index.html` canonical tag and JSON-LD `@id` references
5. Update `public/CNAME`, `public/robots.txt`, `public/llms.txt`, and `public/llms-full.txt`
6. Run `npm run build`

#### Adding a New Public Storefront Page
1. Create the page under `src/app/<name>/page.jsx` with `<SEO ... />` component
2. Add route in `src/App.tsx`
3. Add entry to `STATIC_ROUTES` in `scripts/generate-sitemap.js`
4. Add entry to `STATIC_ROUTES` in `scripts/prerender-seo.js`
5. Add navigation link in `src/components/redesign/Header.jsx` and `Footer.jsx`
6. Run `npm run build`
